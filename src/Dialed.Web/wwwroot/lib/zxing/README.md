# zxing-wasm 3.1.6 (MIT)

Barcode reader used by the barcode scan (#104). Self-hosted: nothing is loaded from a CDN, so the Content-Security-Policy stays closed.

Files, copied unchanged from the npm package `zxing-wasm@3.1.6`:
- `reader/index.js` is `dist/es/reader/index.js`
- `share.js` is `dist/es/share.js`
- `reader/zxing_reader.wasm` is `dist/reader/zxing_reader.wasm`
- `LICENSE`

To update: `npm install zxing-wasm@<version>`, copy the same four files, check the scan on a real device, and update the version here and in `docs/security-review.md`.
